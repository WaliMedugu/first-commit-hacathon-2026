## 📌 Project Overview

**Kilikoro** is an all-in-one developer operating system and proof-of-competence ecosystem engineered to bridge the gap between student learning and industry-standard technical validation.

Modern student builders often face fragmented workflows: tracking builds across disconnected platforms, struggling to prove authentic skill competence against AI-generated templates, and navigating disjointed payment rails. Kilikoro unifies these capabilities into a high-performance web platform:

1. **Deterministic Code X-Ray (Competence Sandbox):** Analyzes code structures via Abstract Syntax Trees (AST), checking cyclomatic complexity, entropy metrics, and Big-O algorithmic scaling ($N = 10 \to 10,000$) to mathematically validate genuine developer logic.
2. **Kilikoro Cryptographic Attestations:** Issues verifiable proof-of-competence credentials signed by verification nodes.
3. **BANK Milestone Settlement Rails:** Seamlessly releases funds into developer wallets and virtual payment cards upon verified milestone completion.
4. **Dual-Mode Workspace:** Instantaneous role toggle between *Personal Developer Workspace* and *Team/Organization Hub*.

## 🚀 Quick Setup & Local Execution

Judges and developers can launch Kilikoro locally in under 30 seconds:

### Prerequisites
* [Node.js](https://nodejs.org/) (v16 or higher)

### 1. Installation
```bash
git clone https://github.com/WaliMedugu/first-commit-hacathon-2026.git
cd first-commit-hacathon-2026
npm install
```

### 2. Run the Full-Stack Application
```bash
# Start the backend server & serve the application
npm start
# or: node server.js
```
Open your browser and navigate to: **`http://localhost:3000`**

### 3. Developer CLI Sandbox (Optional)
```bash
# Run local AST code inspection & assertion sandbox
node kilikoro.js test

# Submit solution & trigger instant BANK escrow release
node kilikoro.js submit

# Check BANK Virtual Mastercard balance
node kilikoro.js balance
```
